### Added

- The fleet has a store on the host: one SQLite file per fleet at `<config-dir>/store/fleet.sqlite`, created by `crew up` if absent, holding every `SESSION END` field as a column beside the ticks, vitals, limit events and raw `duty.log` lines of every box (#758).
- The store holds each member's memory keyed by box — the seen and suppressed ledgers, the breaker and budget state, the decline, resume, auth-fail and stamp files — and a `schema_version` row names the shape (#758).
- The store module documents how 0.1.5's claims, rounds, verdicts, states, handoffs and typed edges sit beside it (#758).
- The floor's collector pulls every box into the store on every poll, shipping only the lines new since the last pull, and `crew drain <box>` pulls the whole of a box in one full probe before it is stopped (#758).
- A pull is one transaction per box: a second pull of the same evidence inserts nothing, a record cut off mid-file lands nothing, and a `duty.log` that was rotated is read again from the top (#758).
- `crew usage [--since 24h|7d] [--by member|pool|kind]` prints sessions, minutes and cost per member, per credential pool or per session kind from the store alone, asking no box (#758).
- Cost is tokens times `shared/conf/model-prices.conf`, parsed and never sourced, and a session whose model is unpriced is counted as unpriced rather than as free (#758).
- A box that does not answer stays reportable: `crew status` prints its last session, last pull and 24-hour cost labelled `stored`, and the console marks an off box with the time of its last pull (#758).
- `/api/fleet` serves an off box's unit from the store with `source: "stored"` and `stored_at`, while a probed box carries `source: "live"` (#758).
- `probe.sh` gains an opt-in full mode (`PROBE_FULL=1`, `PROBE_LOG_FROM=<n>`) that appends one delimited section per state file and one for `duty.log` after the record it has always emitted, which is unchanged byte for byte (#758).
