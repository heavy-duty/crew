### Fixed

- Triage's signal (e) counts a cross-repo blocker (`Blocked by owner/repo#N` or `repo#N`) as a member that is still open instead of dropping it from the set, so an issue whose only standing gate lives in another repository is never nominated as unblockable (#632).
- A cross-repo number that collides with a closed local number no longer resolves against the wrong repository (#632).
- Triage's signal (f) keeps the same dependency edge set for a body that names a cross-repo blocker as for one that does not, rather than fabricating an edge onto the local issue of the same number (#632).
- The `Blocked by` clause ends at a sentence boundary — a `.` or `;` not followed by a letter or digit — instead of at the first literal `.`, so a dot inside a token no longer truncates a declaration (#632).
- A `Blocked by` marker that opens a code span or a quotation is read as a quotation of another issue's clause and declares nothing, so a body quoting a hold clause in prose no longer parses to a phantom blocker set (#632).
