### Added

- The host tick, `crew tick`: one board read per repository per tick on the host, and a box started only when the board moved since its member last looked, the move names work its roles own, and the store's memory of it — ledgers, breakers, budgets — does not already answer it (#759).
- A box that bought no session for `IDLE_TICKS_BEFORE_STOP` ticks is drained to the store and stopped, never while a duty holds its lock and never on a tick that could not read a board; at most `FLEET_MAX_RUNNING` boxes run at once and the rest are held, by name (#759).
- Every `SESSION END` line carries `why=`, the wake's reason as the host wrote it, or `cron` when the box's own cron ticked (#759).
- `crew pause` and `crew resume`: a paused member is never started by the host tick, is drained and stopped if it was running, counts for nothing, and its own cron is commented while it runs — from the verb and from the floor's button alike (#759, #284).

### Changed

- The budgets ship on, with ceilings per lane; rebase, ci-red and hygiene run on the agent profile's cheap tier through the `cheap` alias; hygiene sweeps daily (#759).
