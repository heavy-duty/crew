### Added

- The roster is editable from the floor: `GET /api/roster` reads `fleet.roster` as it is on disk with the agent and role profiles a line may name, and `roster-set` writes it whole — validated line by line, atomically, header comments kept, journalled in `.roster-journal.log` (#764).
- A **Roster** overlay beside **Registries**: one row per box (name, agent, roles, from), add / remove / save, each row's standing read off the poll; a new line becomes a box with `crew up` on the host, a removed line's box is left alone (#764).
