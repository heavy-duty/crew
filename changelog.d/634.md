### Fixed

- `head-checks.jq` no longer grades a head pending when a finished check GitHub left at `status: IN_PROGRESS` carries a set conclusion: `is_pending` is guarded on the conclusion's presence, so such a head grades green, or red when the conclusion is a failure (#634).
- The engine then requests the panel instead of holding the request at a head it would never regrade, while a genuinely running check — `conclusion: null`, or `gh`'s `""` with a zero-time `completedAt` — still holds it (#634).
