### Changed

- `ci-shell` runs one job per suite instead of one serial job: a pull request runs only the suites its changed paths need, read from `.github/ci/suites.map` by `.github/ci/plan.sh`, and any path the map does not name runs everything; a push to `main` and a weekly schedule run the whole matrix (#756).
- The plan reads every page of a pull request's files, plans a renamed file by both its names, and runs everything past 300 files (#756).
- CI restores a pinned, checksummed shellcheck from the cache instead of installing it with `apt-get` on every run, in `ci-shell`, `ci-floor` and the release guards (#756).
- `ci-floor` — the floor's browser walk — runs when `fleet-floor/` moves, weekly on `main`, and by hand on a candidate, no longer on every engine merge; the floor's no-browser suite runs once, in `ci-shell`'s matrix (#756).
- The drill's breaker row grades the label's removal on the attention lane's installed budget through `wait_for_lane`, and `drills/README.md` says which drill legs are offline contract tests and which are the host's round (#756).
