About this floor

This is a god-view of the heavy-duty/crew fleet. Each server room is a box (an isolated VM), each robot is the agent on that box, each rack is a repo it touches, and the office whiteboard is triage.

The feed here is simulated. In production it reads from what the duty engine already emits: one evidence line per tick.sh boundary and SESSION START/END kind=… rc=… dur=… markers in duty.log. Silence across a boundary is the disconnect signal — that's why a quiet box topples over.

Because a box has no inbound path, messaging an agent can't push. It writes to a pull channel the box drains on its next tick — modeled here by the message queue in the inspector.
